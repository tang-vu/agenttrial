# P26-002 human governance evidence

Store human-authored G2/G3 decision memoranda here. Each approval or rejection record must name the exact file and its SHA-256, identify the human decision-maker and date, and bind the current `mainTrialInputDigest` from `research/targets/target-binding-audit.json`.

Evidence should state the decision scope, reviewed artifacts, limitations, conflicts or independence attestations where relevant, and any conditions. Do not place credentials, signing secrets, private raw data, or a submission authorization in this directory. Automated agents may validate these files but may not author or approve the human decisions.
