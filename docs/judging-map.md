# Judging map

| Dimension            | Evidence                                                                                                                                                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Usefulness           | Directly reduces the trust gap for every Orion entry; yields portable receipts marketplaces and buyers can inspect. Judges need no account or key, while builders can opt into ownership-gated A2A active evaluation.                                              |
| Execution            | Live two-agent arena, real retries/repeat runs, 13-state pipeline, deterministic assertions, seed opening, build/registry provenance, Ed25519 tamper detection, hardened adapters, responsive UI, durable worker/signer topology, and machine-readable API.        |
| Originality          | Separates identity from capability proof: “Orion verifies existence; AgentTrial proves performance.” Independent plan sealing defeats outcome cherry-picking; the head-to-head arena makes evidence quality visible without turning evaluation into model opinion. |
| AI vetting readiness | Typed schemas, explicit permissions, untrusted-content isolation, full evidence links, coverage/confidence, honest failure states, reproducible build provenance, and a pin-able assertion-registry manifest.                                                      |
| Community signal     | The launch plan asks builders to test and critique reproducible receipts, never to trade votes or inflate metrics.                                                                                                                                                 |
